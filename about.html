About Project Tools

Project Tools is a lightweight collection of free browser-based utilities for common image and text tasks.

The initial version focuses on practical tools such as image compression, resizing, format conversion, image-to-PDF conversion and word counting. The project is designed to be simple to use on phones and computers.

How it works

Image tools use your browser's built-in image and canvas capabilities. The current prototype does not send selected images to a Project Tools server.

This website is still being developed, so features and pages may change as the project grows.
