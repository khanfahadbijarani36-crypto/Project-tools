Count words, characters and lines instantly.

Use the tool on the main Project Tools page. The current image tools process selected files in your browser rather than sending them to a Project Tools upload server.

Open Word Counter

About this tool

A word counter can help with essays, applications, posts and other writing where you need a quick count of words, characters or lines.

How it works

  1. Open the tool and choose your file or enter your text.
  2. Adjust the available options.
  3. Run the tool and download the result.

Before using the result

For important documents or images, keep your original file and check the downloaded result before submitting or publishing it.

Browser processing

The current prototype performs image operations locally in the browser. Browser/device memory and file format can affect the result.
